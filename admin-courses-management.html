📚 Add / Edit Course

⏳ Course Validity
♾️ Unlimited: Course की कोई expiry नहीं होगी।
📅 Validity Days: Course purchase/start होने की तारीख से दिए गए दिनों तक valid रहेगा।
🗓️ Date Range: Admin द्वारा निर्धारित Start Date से Expiry Date तक valid रहेगा।
💡 Pricing System

📚 Normal Course: पूरे course का individual price होगा।
🎟️ Test Series: पूरी test series का एक price होगा।
📝 Individual test का अलग price यहाँ manage नहीं होगा।
🔓 Test Series purchase होने पर included tests access होंगे।
🆓 Free चुनने पर price ₹0 रहेगा।
Example:

📚 SSC Foundation → ₹499
📚 Maths Course → ₹299
🎟️ SSC Test Series → ₹199
